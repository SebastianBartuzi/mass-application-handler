# mass-application-handler

This application allows to automate the process of sending question requests to local governments in Poland.
The program creates PDF files and sends e-mails with them attached, therefore saving a lot of time.

1. Install dependencies from pyproject.toml
2. Check assets/input folder: replace application.docx (leave under the same name) with the application template desired; update any local authorities data in data.xlsx (governors change throughout the term, so it is advisable to have this data up-to-date)
3. Run run.py to send e-mails

In case of any technical issues, feel free to contact me.
